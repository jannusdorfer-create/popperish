Be the NPC

A game character cannot look outside its game. But it can run tests inside it. Here are four, computed live in your browser with the same rules as our engine: 60 ticks a second, 32-bit positions, collisions checked once per tick.

Test 1

Drop a ball

The game only updates 60 times a second, so every fall lasts a whole number of ticks. Real falls do not.
